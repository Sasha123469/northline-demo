NORTHLINE STUDIO — NEW SUPABASE

1. Open script.js.
2. Replace PASTE_NEW_SUPABASE_PROJECT_URL_HERE with the URL of the NEW Supabase project.
3. Replace PASTE_NEW_PUBLISHABLE_KEY_HERE with the NEW Publishable key (sb_publishable_...).
4. Upload index.html, services.html, style.css and script.js together.
5. Supabase > Authentication > URL Configuration:
   Site URL = your GitHub Pages URL
   Redirect URL = the same GitHub Pages URL
6. Authentication > Sign In / Providers:
   Email = Enabled
   Allow new users to sign up = Enabled
   Confirm email = Enabled if you want verification emails.

Do NOT use a Secret key in the browser.
